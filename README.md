# Advent of Code

Solutions to [Advent of Code](https://adventofcode.com/), an annual series of programming puzzles released each December.

This repository contains my solutions written in Python, covering Advent of Code from 2022 through 2025.

Solutions are organised by year, with each day's solution stored separately.

Puzzle input files are not included in this repository.

## About Advent of Code

Advent of Code is a collection of small programming puzzles that cover a wide range of topics, including algorithms, data structures, mathematics, parsing, simulation, and problem solving. Each day's puzzle consists of two related parts that build upon the same input and problem.

*I use Advent of Code as an opportunity to practise programming, explore different approaches to problems, and learn new techniques outside of university coursework.*
